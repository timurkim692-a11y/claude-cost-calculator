# claude-cost-calculator

Калькулятор стоимости моделей Claude: модель, effort и размер задачи.

**Сайт:** https://timurkim692-a11y.github.io/claude-cost-calculator/

Выбираете модель, уровень effort и размер задачи — калькулятор показывает стоимость по API-тарифам Anthropic, разбивку по входу и выходу и ту же задачу на всех моделях для сравнения.

## Как считается

```
стоимость = ( вход без кэша × цена входа
            + вход из кэша  × цена чтения кэша
            + выход × множитель effort × цена выхода ) / 1 000 000
            × скидка batch × запуски
```

Цены в USD за 1M токенов. Effort по умолчанию — `high`, кроме Opus 5.5.

### Effort

У Anthropic **нет официальных множителей токенов** для уровней effort, поэтому это оценка. Effort управляет глубиной размышлений, а размышления (thinking) оплачиваются как выходные токены, поэтому множитель применяется только к выходу:

| low | medium | high | xhigh | max |
|---|---|---|---|---|
| ×0.4 | ×0.7 | ×1.0 | ×1.5 | ×2.2 |

Множители лежат в `pricing.json` (`effortOutputMultipliers`), их можно откалибровать по реальным `usage.output_tokens`, прогнав одну задачу на разных уровнях effort.

### Размеры задач

Заданы для effort `high`:

| | S | M | L | XL |
|---|---|---|---|---|
| Вход | 5 000 | 30 000 | 150 000 | 500 000 |
| Выход | 1 000 | 5 000 | 20 000 | 60 000 |

Или «Своё» — свои количества токенов.

### Опции

- **Кэш** — доля входа, прочитанная из кэша, по цене чтения кэша конкретной модели (0.1× входа; 0.05× у Opus 5.5; 0.025× у Fable 5.1). Запись в кэш (1.25× / 2× входа) не учитывается.
- **Batch API** — −50% на все токены.
- **Fast mode** — только Opus 5.5 / 5 / 4.8, свои цены входа и выхода, кэш-множитель модели применяется к цене fast. Несовместим с batch.
- **Запуски** — сумма за N запусков задачи.

### Сравнение моделей

Та же задача на всех моделях, от дешёвой к дорогой. Если модель не поддерживает выбранный effort, берётся её effort по умолчанию (пометка `*`); fast mode применяется только там, где он есть (пометка «без fast»).

### Ограничения

- Множители effort — оценка, реальный расход зависит от задачи.
- Не учитываются запись в кэш, серверные инструменты (web search — $10 за 1000 запросов), US-only inference (×1.1) и цены Bedrock / Google Cloud.
- **Подписка Pro/Max**: работа в пределах лимитов плана отдельно не оплачивается. По API-тарифам считаются usage credits сверх лимита и fast mode — он всегда списывается из usage credits.

## Разработка

```bash
npm install
npm run dev       # интерфейс на http://localhost:5173
npm test          # Vitest
npm run typecheck # tsc
npm run build     # сборка в dist/
```

Структура:

- `src/data/pricing.json` — цены, множители effort, размеры задач
- `src/pricing.ts` — расчёт: `estimateCost`, `compareModels`
- `src/ui/` — интерфейс без фреймворков и форматирование чисел
- `src/*.test.ts`, `src/ui/*.test.ts` — тесты

## Деплой

`.github/workflows/deploy.yml` собирает сайт и публикует его на GitHub Pages при каждом пуше в `main`. Один раз нужно включить Pages: **Settings → Pages → Source: GitHub Actions**.

`.github/workflows/ci.yml` прогоняет тесты и сборку в pull request'ах и остальных ветках.
