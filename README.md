# claude-cost-calculator
Калькулятор стоимости моделей Claude: модель, effort и размер задачи

## Как считается

```
стоимость = (вход без кэша × цена входа
           + вход из кэша × цена чтения кэша
           + выход × множитель effort × цена выхода) / 1 000 000 × запуски
```

- **Цены** — `src/data/pricing.json`, по [официальной таблице Anthropic API](https://platform.claude.com/docs/en/about-claude/pricing). Обновлять только этот файл.
- **Effort** — у Anthropic нет официальных множителей токенов, поэтому это *оценка*: базой считается `high = 1.0`, `low ×0.4`, `medium ×0.7`, `xhigh ×1.5`, `max ×2.2`. Множитель применяется к выходным токенам (в них входит thinking).
- **Размеры задач** (при effort high): S — 5k вход / 1k выход, M — 30k / 5k, L — 150k / 20k, XL — 500k / 60k.
- **Опции**: доля кэш-попаданий, Batch API (−50%), fast mode (Opus 5.5 / 5 / 4.8, не совместим с batch), число запусков.
- Запись в кэш (1.25× / 2× цены входа) пока не учитывается.
