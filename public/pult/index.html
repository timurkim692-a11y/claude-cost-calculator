    Ключ доступа GitHub (fine-grained token)
    Как получить ключ
    1. Откройте github.com/settings/personal-access-tokens/new.
    2. Token name: «Пульт». Expiration: 1 год (Custom).
    3. Repository access: Only select repositories → claude-pult.
    4. Permissions → Repository: Contents — Read and write, Issues — Read and write.
    5. Generate token, скопируйте и вставьте сюда. Ключ хранится только на этом устройстве.
    Как это работает

    Кнопка создаёт задачу в репозитории. GitHub запускает Claude Code с вашим скиллом и доступом к Google Таблицам, Claude пишет ход работы и вопросы в задачу. Ваш ответ из пульта запускает его снова. Расход — из подписки Claude.
